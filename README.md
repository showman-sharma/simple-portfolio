# Anirudh Sharma — Portfolio

A handcrafted, interactive portfolio for my work across **AI/ML engineering, research, LLM systems, agents, evaluation, reasoning, and open source**.

## Design philosophy

This site is intentionally not a résumé rendered as cards. It is designed as a technical narrative: what I build, what I research, how my work evolved, and the engineering questions I care about now.

### Interaction

- responsive editorial layout
- dark/light theme with local preference persistence
- interactive project filtering
- scroll-reveal transitions
- cursor-reactive ambient lighting
- subtle 3D terminal interaction on desktop
- reduced-motion support for accessibility

## Featured work

The site foregrounds a small set of projects with the strongest technical or research signal, including:

- Drug–Adverse Event Reasoner
- Code Generation Research
- Agentic RAG
- Bio-inspired Similarity Search & Clustering
- Gradient Ascent Syndicate
- AI/ML Newsletter Automation
- Enterprise AI whitepapers

## Stack

Deliberately lightweight: semantic HTML, modern CSS, and vanilla JavaScript. No framework is required to load or understand the site.

## Run locally

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
